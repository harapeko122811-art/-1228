# 収益化計画書

**基本原則**：収益を理由に情報の正確性・中立性を犠牲にしない。広告・PRは常に明示する。広告審査の合格や収益の発生は保証されない。本計画書に記載する数値は計画上の仮定であり、実績ではない（現時点でアクセス数・収益の実績はゼロ）。

## 1. 現状（2026-11-02 時点）

| 項目 | 状態 |
|---|---|
| 広告枠 | 主要ページ（トップ、各機関、テーマページ、研究記事）に「広告枠」コンポーネント（`AdSlot`）を配置済み。広告は未配信で、枠には「現在、広告は掲載していません」と表示 |
| アフィリエイト | `content/books.ts` の `affiliateUrl` を設定すると「PR（アフィリエイトリンク）」表示つきで `rel="sponsored"` リンクが出る構造を実装済み。現在リンクなし |
| 有料レポート | `/reports/` に構想を掲載（販売・決済機能なし） |
| メールマガジン | `/reports/` に準備中と表示。登録フォームは未実装 |
| 必須ページ | プライバシーポリシー、広告掲載方針、免責事項、運営・問い合わせページを整備済み |

## 2. 短期（公開〜6か月）：信頼の獲得と基盤づくり

1. **原文照合の完了と内容の充実**：`docs/TODO.md` の照合を完了させる。広告審査（AdSense 等）は独自性・有用性のあるコンテンツ量と運営者情報・問い合わせ窓口の明示が前提となるため、記事を継続的に追加する（目安：研究記事を月2〜4本）。
2. **AdSense 等の申請**：運営者情報・問い合わせ窓口・プライバシーポリシー（Cookie利用の記載を追記）を整えてから申請する。合格した場合、`AdSlot` コンポーネントの中身を広告タグに差し替える（クライアントIDは環境変数 `NEXT_PUBLIC_ADSENSE_CLIENT` で管理）。審査に通らない可能性があることを前提に計画する。
3. **書籍アフィリエイト**：安全保障・インテリジェンス、情報分析、語学、統計、情報セキュリティ関連書籍を、編集部が実際に参照・評価したものに限って紹介する。報酬の有無で選定・評価を変えない。
4. **計測**：アクセス解析を導入する場合は、プライバシーポリシーを先に改定する。

## 3. 中期（6か月〜2年）：独自価値の有料化

| 商品 | 内容 | 前提条件 |
|---|---|---|
| 組織比較資料（詳細版） | 7区分の法的根拠・組織・定員・予算の年度別比較（PDF/Excel） | 一次資料との完全照合 |
| 月次レポート | 国家情報会議・有識者会議・関連法案・各機関の再編の月次分析 | 継続的な調査体制 |
| 有料会員記事 | 詳細分析・論点整理。無料記事の質を落とさないことを条件とする | 決済・会員管理（note、Substack 等の外部サービスの活用から開始） |
| 学習教材 | OSINT の調べ方、出典評価、構造化分析手法の入門教材 | 教育的な正確性の検証 |
| メールマガジン | 無料版（更新通知）と有料版（月次分析） | 配信サービスの選定、個人情報保護 |

まずは外部プラットフォーム（決済・会員管理を外部に委ねる）で需要を検証し、自前の決済機能は需要が確認できてから検討する。

## 4. 長期（2年〜）：専門メディア化

- 研究者・実務経験者への寄稿依頼（寄稿料の支払い、利益相反の開示ルールの整備）
- 独自調査・アンケート（調査倫理と個人情報保護の手続を整えたうえで）
- 法人向け調査レポート（経済安全保障・技術流出対策の制度解説等。特定企業の利害に偏らない）
- 大学・研究機関との連携（教材提供、共同研究）

## 5. リスクと対策

| リスク | 対策 |
|---|---|
| 広告が中立性を損なう | 広告掲載方針の遵守、政治的意見広告・監視ツール広告の不掲載 |
| ステルスマーケティング規制 | PR 表示の自動付与（実装済み）、記事内の個別表示 |
| 誤情報による信用失墜 | 出典台帳と確認状況の公開、訂正方針と訂正履歴 |
| 収益が出ない | 低コストの静的サイト構成（ホスティング費ほぼゼロ）で継続性を確保 |
| テーマの性質上の安全上の懸念 | 公開情報のみ扱い、個人特定・活動妨害に関わる情報は扱わない方針を明示 |

## 6. 次に取り組むべきこと（優先順）

1. 原文照合を完了し、運営者情報と問い合わせ窓口を設定して公開する
2. 研究記事を継続的に追加し、検索エンジンへの登録を行う
3. 書籍紹介ページを拡充（アフィリエイト登録はその後）
4. 一定のコンテンツ量に達した段階で広告審査を申請する
5. 月次レポートの試作版を無料で公開し、需要を確かめる
